FreeLament Extrusion System

Smart filament extrusion system for recycling plastic straws into reusable 3D printing filament using dual ESP32 microcontrollers, PID temperature control, live monitoring, and automated winding.

Overview

FreeLament is a capstone project focused on converting used plastic straws into reusable 3D printer filament. The system combines mechanical extrusion, temperature control, web monitoring, and filament winding into a semi-automated recycling platform.

The project uses:

ESP32-based PID temperature controller
MAX6675 thermocouple monitoring
Heating element with SSR control
Motorized auger extrusion
Diameter sensor and filament winder
ESP32-CAM live monitoring
Web dashboard with authentication
PHP + MySQL backend system

The machine framework uses aluminum extrusion profiles for modularity and easier maintenance.
